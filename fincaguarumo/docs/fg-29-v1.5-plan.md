# FG-29 V1.5 Implementation Plan: Benchmark Harness & Promotion Recommendations

## Overview

V1.5 implements the benchmarking infrastructure and promotion recommendation system as specified in the FG-29 feature spec. This phase focuses on automated evaluation and recommendation without automatic promotion.

## Scope

### In Scope
- Benchmark harness for multilingual RAG evaluation
- Nightly smoke checks on golden datasets
- Weekly comprehensive benchmark jobs
- Promotion recommendation system
- Benchmark result storage and analysis
- Regression detection and reporting

### Out of Scope (Deferred to V2)
- Semi-automatic promotion execution
- Canary rollout system
- Automatic model switching
- Rollback triggers and execution

## Implementation Components

### 1. Benchmark Harness (`scripts/benchmark-models.ts`)

**Core Functions:**
```typescript
interface BenchmarkConfig {
  modelId: string
  provider: string
  role: string
  dataset: string
  metrics: BenchmarkMetrics
}

interface BenchmarkResult {
  modelId: string
  provider: string
  role: string
  timestamp: Date
  weightedScore: number
  individualMetrics: {
    retrievalRelevance: number
    crossLingualRetrieval: number
    groundedAnswerAccuracy: number
    faithfulness: number
    structuredOutputValidity: number
    toolCallingRobustness: number
    latency: number
    costEfficiency: number
  }
  regressionFlags: string[]
  costMetrics: {
    costPerTask: number
    tokensUsed: number
  }
}
```

**Key Functions:**
- `runBenchmark(config: BenchmarkConfig): Promise<BenchmarkResult>`
- `compareModels(candidate: BenchmarkResult, incumbent: BenchmarkResult): ComparisonReport`
- `generatePromotionRecommendation(candidate: BenchmarkResult, incumbent: BenchmarkResult): PromotionRecommendation`

### 2. Dataset Management (`benchmarks/datasets/`)

**Internal Golden Sets:**
- Hospitality/tourism domain-specific content
- Multilingual queries (ES, EN, NL, mixed-language)
- Ground truth relevance judgments
- Faithfulness evaluation rubrics

**Public Benchmarks Integration:**
- MIRACL: Core multilingual retrieval
- MMTEB: Broad embedding evaluation
- MLDR: Long-document multilingual retrieval
- MEMERAG: End-to-end multilingual RAG quality
- BEIR: English zero-shot robustness baseline

**Structure:**
```
benchmarks/results/

    └── ...
```

**Required Fields:**
- modelId, provider, role, timestamp
- weightedScore, individualMetrics
- regressionFlags, costMetrics
- dataset version, benchmark version

### 4. Promotion Recommendation Engine

**Scoring Formula (per spec):**
- Retrieval relevance: 20%
- Cross-lingual retrieval: 15%
- Grounded answer accuracy: 20%
- Faithfulness: 20%
- Structured output/tool reliability: 10%
- Latency: 10%
- Cost efficiency: 5%

**Promotion Criteria:**
- Total weighted score beats incumbent by ≥5%
- Faithfulness regression ≤1%
- Structured output validity ≥98%
- p95 latency within SLA
- Failure recovery <5 seconds
- Confirmed in 2 consecutive benchmark runs

**Output Format:**
```typescript
interface PromotionRecommendation {
  candidateModel: string
  incumbentModel: string
  role: string
  recommendation: "promote" | "keep" | "investigate"
  confidence: number
  reasoning: {
    weightedScoreImprovement: number
    guardrailRegressions: string[]
    costImprovement: number
    riskFactors: string[]
  }
  requiredRuns: number
  completedRuns: number
}
```
